# 📊 E-Commerce Sales Analytics Engine

A modular, object-oriented data science pipeline built to process, store, and analyze large-scale e-commerce transactional data using Python, SQLite, and Pandas.

---

## 🚀 Project Overview
This project simulates an end-to-end data analytics workflow. It ingests raw retail sales data, cleans and validates it, stores it in a structured relational SQLite database, and executes high-performance analytical queries to extract critical business insights.

---

## 🛠️ Tech Stack & Tools
* **Python** (Core Logic & Automation)
* **Pandas** (Data Cleaning & Manipulation)
* **SQLite & SQL** (Relational Database Storage & Querying)
* **Git & GitHub** (Version Control & Collaboration)
